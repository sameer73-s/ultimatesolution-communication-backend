# ADR-004 — حدود تكامل ذكاء الاجتماعات في WBS 3.5

| الحقل | القيمة |
|---|---|
| الحالة | **مقبول** |
| التاريخ | 2026-08-28 |
| القرار | تنفيذ نموذج وحوكمة ذكاء الاجتماعات بعقود عامة ومحولات اختبارية حتمية، مع تأجيل الربط التشغيلي لـWhisper وClaude والبنية الداعمة إلى خطوة مستقلة لاحقة. |

## السياق

تتطلب ميزة ذكاء الاجتماعات تفريغ التسجيلات وإنشاء ملخصات وقرارات ومهام مستخرجة. يفرض الدليل المعماري بقاء الذكاء الاصطناعي خارج الـAPI الرئيسي، مع حصر أي تفاصيل مزود داخل Infrastructure أو خدمة مستقلة. في الوقت ذاته، لا تتوفر بعد قرارات الاستضافة والطابور والتخزين والاحتفاظ اللازمة لتشغيل معالجة صوت حقيقية وآمنة.

## القرار

تنفذ WBS 3.5 الآن الكيانات `TranscriptionJob` و`TranscriptionSegment` و`MeetingSummary` و`ActionItem`، وعقود Application المحايدة `ITranscriptionService` و`ISummaryService`، وسياسة `IMeetingSummaryApprovalPolicy`. ينشئ التلخيص دائمًا `MeetingSummary` بحالة `Draft`، ولا تصبح المهام `ActionItem` دائمة إلا بعد نجاح سياسة الاعتماد وانتقال الملخص إلى `Approved`.

تُنفّذ في Infrastructure محولات عامة قابلة للتهيئة إلى خدمة ذكاء اجتماعات خارجية، ويستبدلها محول اختباري حتمي في بيئة `Testing`. لا يحوي API أو Application أو Domain اسم مزود أو مسار API أو SDK خاصًا بالتفريغ أو التلخيص.

## المؤجل صراحة

| البند | الحالة في WBS 3.5 | الخطوة اللاحقة المطلوبة |
|---|---|---|
| Whisper للتفريغ | لا يوجد ربط فعلي. لا يفترض العقد API سحابيًا مُدارًا. | توصيل Whisper مفتوح المصدر مُستضاف ذاتيًا من خلال تنفيذ Infrastructure أو خدمة مستقلة. |
| Claude للتلخيص واستخراج المهام | لا يوجد ربط فعلي أو سر في هذا التغيير. | تنفيذ محول الخدمة المستقلة وتكوين الأسرار خارج المستودع. |
| الاستضافة والطابور وإعادة المحاولة | غير محسومة ولا توجد معالجة خلفية داخل API الرئيسي. | اعتماد خدمة تشغيل مستقلة وطابور دائم وسياسة إعادة محاولة. |
| التخزين والاحتفاظ والتشفير | غير محسومة ولا تحفظ WBS 3.5 ملفات صوت أو نصوص خارج نموذجها. | اعتماد Object Storage وسياسة احتفاظ وتصنيف وتشفير قبل الإنتاج. |

> **قاعدة إلزامية:** لا يُعامل المحول الاختباري أو أي إعداد تطويري على أنه تكامل إنتاجي. لا يجوز تفعيل معالجة صوت أو ملخصات حقيقية قبل اعتماد بنية الخدمة المستقلة، وسياسة الاحتفاظ، والمفاتيح والأسرار التشغيلية.

## النتائج

يبقى نموذج المجال وحوكمة المراجعة قابلين للاختبار من طرف إلى طرف دون ربط مزود حقيقي. كما يسمح فصل `ITranscriptionService` و`ISummaryService` بإضافة Whisper المُستضاف ذاتيًا وClaude لاحقًا من دون تغيير أوامر CQRS أو Controllers أو Flutter. وتبقى قابلية توسيع اعتماد الملخص محكومة بـ`IMeetingSummaryApprovalPolicy` بدلاً من فحص دور ثابت داخل Handler.
